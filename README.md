# Cursos (copias de respaldo `.mbz`)

## Cómo exportar un curso SIN datos de usuarios
1. Entra al curso → *Más* → *Copia de seguridad*.
2. **Desmarca** «Incluir usuarios matriculados», «Incluir asignaciones de rol» y todo dato de usuario.
3. Mantén las actividades, recursos, banco de preguntas y configuración.
4. Descarga el `.mbz` desde *Zona privada de copias de seguridad*.
5. Nómbralo así: `curso_<area>_v<numero>.mbz`.

## Archivos
| Archivo | Descripción | Sprint |
|---|---|---|
| `curso_plantilla_v1.mbz` | Curso plantilla con ADDIE y Bloom | 5 |
| `curso_<area1>_v1.mbz` | `[COMPLETAR]` | 5 |
| `curso_<area2>_v1.mbz` | `[COMPLETAR]` | 6 |
| `curso_<area3>_v1.mbz` | `[COMPLETAR]` | 7 |

> Si un `.mbz` supera los 100 MB, usa Git LFS o enlázalo desde un almacenamiento externo.
